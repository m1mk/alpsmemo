# alpsmemo（替え歌暗記ツール）

覚えたい文章を、AI（Claude）が「アルプス一万尺」のリズムに乗る替え歌にし、VOICEVOX で WAV にします。
設計は `../替え歌暗記ツール 設計書（アルプス一万尺×VOICEVOX）.md` を参照。

## 準備（初回のみ）

1. VOICEVOX を起動する
2. Claude Code にログインする：`claude auth login`（歌詞生成は `claude -p` 経由で、claude.ai のサブスク内で動きます）
   - APIキー（従量課金）で動かしたい場合は、`config.toml` の `[ai] backend = "api"` にして `setx ANTHROPIC_API_KEY "sk-ant-..."`
3. このフォルダで仮想環境を有効にする：`.venv\Scripts\Activate.ps1`
   （作り直す場合：`py -3.14 -m venv .venv` → `pip install -e .[dev]`）
4. `alpsmemo check` で話者IDを確認し、必要なら `config.toml` を書き換える

## 使い方（GUI）

デスクトップの「替え歌暗記ツール」をダブルクリック（または `alpsmemo gui`）。

1. テーマ名を入れ、覚えたい文章を貼り、「曲」を選んで「歌詞を作る」（曲の選び方は下の表）
2. 歌詞の一覧で数字・用語・読みを確認（★は要確認）。行をクリックすると、右の「3. 選んだブロックを直す」にそのブロックの全行が出ます
3. 「音声を作る」
4. 「▶ 再生」で、今歌っている行と音を表示しながら再生
5. スマホなどに渡すときは「この音声を別の場所にコピー…」で .wav をコピー（「コピー先を開く」でその場所が開きます）

歌詞も音声もテーマごとに `out\テーマ名\` へ自動で保存されます。前に作ったものは「作ったもの一覧…」から開きます（更新日時・ブロック数・音声の有無・冒頭の歌詞が見えます。削除もここから）。「このフォルダをエクスプローラーで見る」は、その保存先フォルダをエクスプローラーで開くだけのボタンです。

### 歌詞の直し方（3. 選んだブロックを直す）

- 歌詞（表示用）と読み（カタカナ）を直接書き換えます。読みを変えると、音符の図と音数（例 `6 / 8`）がその場で変わります
- 音が足りないときは「埋める▼」から選びます
  - **伸ばして埋める（ー）**：前の音を伸ばして歌う。メロディが途切れないので、まずこれを試してください
  - **繰り返して埋める**：読みをもう一度繰り返す（例：イツカ → イツカイツカ）
  - **休符で埋める（＿）**：その音は歌わずに休む
  - **読みを自動で付ける（VOICEVOX）**：歌詞（表示用）から読みを付ける。数字・専門用語の読みは確認してください
- 自分で音数を合わせるのが面倒なときは「AIに直してもらう…」。今の歌詞・読み（音数が合っていなくてOK）と、ひとことの指示（例「3行目を短く」）を元に、AIが音数を合わせて作り直します。結果は確認してから「このブロックを保存」（Ctrl+S）
- 原文・キーワードも同じ画面で直せます。「元に戻す」で保存前の状態に戻ります

ブロックごと消すときは「このブロックを削除」。

## 曲

| 曲 | 行×音数 | 向いている内容 |
|---|---|---|
| アルプス一万尺（標準） | 8・6・8・6 | 条件と数値の組をひとまとまりで |
| きらきら星 | 7×6行 | 長めの説明を行ごとに区切って覚える |
| 線路は続くよどこまでも | 7・5・7・6 | 手順・工程を「次、次」と順番に |
| メリーさんのひつじ | 7・6・8・5 | 歌いやすい。数字・基準値の丸暗記 |
| ジングルベル（サビ） | 6・5・8・6 ×2 | 同じ旋律が戻るので、大事なキーワードを繰り返す |
| 森のくまさん | 3・3・5・5・5・5・4・4 | 問いと答えの掛け合い。紛らわしい2択の区別 |

どの曲で作ったかは `lyrics.json` に記録され、音声化でも同じ曲が使われます。
「線路は続くよどこまでも」と「森のくまさん」は楽譜なしで書き起こしたため、音程が実際と違うかもしれません（画面に「※音程は要確認」と出ます）。`melodies/*.json` の `[key, beats]`（key は MIDI 番号、C=60）を耳で聴いて直してください。曲を増やすときも、同じ形式の JSON を `melodies/` に置くだけです。

## 使い方（コマンド）

```
alpsmemo lyrics 入力.txt -o out/テーマ名     # 歌詞を生成 → lyrics.json / lyrics.txt
alpsmemo synth out/テーマ名                  # 音声化（既定は歌唱。--mode read で読み上げ）
alpsmemo run 入力.txt -o out/テーマ名         # 上の2つを続けて実行
alpsmemo check                               # VOICEVOXの起動確認と話者一覧
alpsmemo melodies                            # 使える曲の一覧
```

共通オプション：`--bpm`、`--repeat N`、`--click` / `--no-click`、`--transpose 半音`、`--melody ファイル`。
入力ファイルの代わりに `-` を指定すると、文章を貼り付けて入力できます。

### 音声化の前に必ず歌詞を確認する

`lyrics.txt` で数字・用語が原文どおりか確認し、直すときは `lyrics.json` を編集します。

- `morae` は `["イ","ツ","カ"]` のような配列のほか、`"イツカ"` のように文字列で書いても自動で分割されます
- `ー` は前の音を伸ばします（歌唱では前の母音で歌い続ける）。音が足りないときは休符より自然です
- `＿`（または `_`）は休符です。その音符では歌いません
- 自動修正できなかったブロックは `"needs_review": true` になっています。確認したら `false` にしてください
- `synth` は音数が合わないブロックをスキップして、残りを出力します

## 出力

`out/テーマ名/sing/`（読み上げは `read/`）に次のファイルを出力します。

- `block_01.wav` …：ブロックごとの音声
- `all.wav`：全ブロックの結合（ブロック間に1小節の無音）
- `all_repeatN.wav`：各ブロックをN回繰り返した版（`--repeat 2` 以上のとき）
- `timing.json`：各音の開始時刻（GUIの歌詞表示用）

## 調整

- メロディ：`melodies/*.json`（`[key, beats]`、key は MIDI 番号、休符は `null`、`title`・`description` が画面に出る）。耳で聴いて直してください
- AIへの指示：`prompts/lyrics_system.md`（ルール）、`lyrics_user.md`（依頼文）、`lyrics_fix.md`（作り直し依頼）、`lyrics_edit.md`（GUIの「AIに直してもらう」）
- テスト：`pytest`（VOICEVOX 起動中は実エンジンでの長さ・歌唱テストも実行）

生成音声を公開・共有する場合は、VOICEVOX と各キャラクターの利用規約・クレジット表記に従ってください。
